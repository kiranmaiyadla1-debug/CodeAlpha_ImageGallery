## 📌 Project Overview

This project is a modern image gallery that allows users to:

- View images in a grid layout
- Filter images by categories
- Open images in a full-screen lightbox
- Navigate between images using next/previous buttons
- Enjoy smooth animations and hover effects

---

## ✨ Features

✔ Responsive grid-based image gallery  
✔ Category filtering (All, Vehicles, Nature, People)  
✔ Lightbox image preview  
✔ Next / Previous navigation inside lightbox  
✔ Smooth hover zoom effects  
✔ Click outside / close button to exit preview  
✔ Mobile-friendly design

## ⚙️ How It Works

### 🔹 Filtering Images
Click on category buttons to show only selected images.

### 🔹 Lightbox View
Click on any image to open it in full-screen mode.

### 🔹 Navigation
Use:
- ⬅ Previous image
- ➡ Next image
- ❌ Close lightbox
